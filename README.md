# Swiss Tech Lead Generation Project

## Project Overview
Collected and enriched LinkedIn data of Software 
Engineers from Swiss Tech companies.

## Data Includes
- Company Name & Website
- First & Last Name
- Job Title
- City (Zurich, Bern, Basel, St. Gallen)
- Email Address
- Phone Number
- LinkedIn URL
- Verification Date

## Skills Used
- Lead Generation
- LinkedIn Research
- Data Enrichment
- Apollo.io Tool
- Google Sheets
